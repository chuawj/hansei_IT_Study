# 한세대학교 수강신청 연습 시스템

## 소개
이 프로젝트는 한세대학교 수강신청 시스템을 실제와 유사하게 연습할 수 있도록 만든 웹 기반 모의 사이트입니다. 실제 수강신청 사이트의 UI/UX를 최대한 비슷하게 구현하여, 누구나 자유롭게 수강신청 과정을 체험하고 연습할 수 있습니다.

## 주요 기능
- **교과목 조회**: 학부/학과/이수구분/과목명 등 다양한 조건으로 교과목을 검색할 수 있습니다.
- **예비수강신청**: 원하는 과목을 예비로 신청/삭제할 수 있습니다. (로컬 저장)
- **수강신청**: 실제 수강신청처럼 과목을 신청/삭제할 수 있습니다. (로컬 저장)
- **수강내역 조회**: 신청 완료한 과목만 따로 확인할 수 있습니다.
- **수강신청 오픈 타이머**: 원하는 시간에 수강신청이 열리도록 타이머를 설정할 수 있습니다.
- **실제와 유사한 UI/UX**: 한세대학교 실제 시스템과 비슷한 화면 구성과 조작 방식을 제공합니다.

## 만든 이유
- 실제 수강신청 시스템은 연습이 불가능하고, 실수 시 자기 부담의 불이익이 있을 수 있습니다.
- 학생들이 사전에 수강신청 과정을 충분히 연습해보고, 실전에서 당황하지 않도록 돕기 위해 제작했습니다.
- UI/UX, 기능, 흐름을 미리 익혀두면 실제 수강신청 때 실수를 줄이고, 원하는 과목을 더 쉽게 신청할 수 있도록 연습 환경을 제공합니다.

## 참고 및 주의사항
- 이 사이트는 연습/테스트용으로만 사용되며, 실제 학교 시스템과는 아무런 연동이 없습니다.
- 신청/삭제/마감 등 모든 동작은 브라우저(로컬)에만 저장되고, 서버로 전송되지 않습니다.
